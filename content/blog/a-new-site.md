This site used to be a WordPress blog. It is now a small desktop in the browser: the icons open windows, the windows can be moved, resized and minimized, and every window has its own address that can be bookmarked or shared.

Underneath, it is a static site built with [React Router](https://reactrouter.com). Every page is rendered to plain HTML when the site is built, so it loads quickly and reads well for search engines, and posts like this one are Markdown files kept next to the code.

The posts and pages from the old site are on their way over.
